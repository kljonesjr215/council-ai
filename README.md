# Council AI

Council is a personal AI deliberation workspace.

## V1 goals
- Ask GPT and Claude from one conversation
- Challenge either model or both before reaching a decision
- Keep the human in control of the final decision
- Organize conversations by project
- Prepare for persistent memory and multimodal evidence
- Support images, documents, voice notes, and a future video/live-media pipeline

## Status
V1 is under active development.
